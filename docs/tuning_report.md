# 调优实验记录

以下数据来自当前演示数据的真实 Spark local[*] 运行，不能代表 1 亿条全量数据的生产耗时。

| 实验 | 配置 | 结果 | 耗时（秒） |
|---|---|---:|---:|
| shuffle 并行度基线 | 200 | 36 | 0.741 |
| shuffle 并行度调整 | 400 | 36 | 0.292 |
| 普通 join | - | 119,955 | 0.662 |
| broadcast join | - | 119,955 | 0.511 |

解释：DWS/ADS 聚合中可通过 `spark.sql.shuffle.partitions` 调整并行度；小维表 join 可使用 `broadcast()`，减少不必要的 shuffle。真实数据运行后应在同一机器和相同输入下重复实验，再将全量结果用于简历。
