# 数仓分层设计

## ODS
保留原始字段并增加 `dt` 分区字段，不在贴源层删除记录，支持回溯和重跑。

## DWD
一行表示一条有效用户行为。按日期范围过滤、过滤用户或商品空值、按 `(user_id,item_id,behavior_type,ts)` 去重，并生成 `is_pv/is_cart/is_fav/is_buy` 标记列。

## DWS
按用户+日期、商品+日期、类目+日期三个粒度构建汇总宽表。粒度明确后，ADS 多个指标可以复用聚合结果，避免重复扫描 DWD。

## ADS
产出面向业务的 DAU、留存、漏斗、类目 Top10 和复购率结果，供报表或可视化使用。
