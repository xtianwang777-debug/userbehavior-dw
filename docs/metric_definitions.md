# 指标口径字典

| 指标 | 分子 | 分母 | 去重/窗口 | 来源 |
|---|---|---|---|---|
| DAU | 当日活跃用户数 | - | `COUNT(DISTINCT user_id)` | DWD |
| 次日留存 | 当日活跃用户中次日仍活跃用户数 | 当日活跃用户数 | `LEFT JOIN`，两侧用户去重 | DWD |
| 7 日留存 | 当日活跃用户中未来 1-7 日任意一天活跃用户数 | 当日活跃用户数 | 区间口径，不是第 7 日精确留存 | DWD |
| 漏斗转化 | 后一行为 UV | 前一行为 UV | 各行为按用户去重 | DWD |
| 类目 Top10 | 类目购买次数 | - | 按 `buy_cnt` 降序 | DWS category |
| 复购率 | 至少两个不同购买日期的用户数 | 窗口内购买用户数 | 按不同 `dt` 计数 | DWD |

所有比率在分母为 0 时输出 0，避免除零。类目 Top10 的排序依据是购买次数，不是购买人数。
