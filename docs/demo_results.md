# 演示运行结果

本页记录 `run_demo.ps1` 在 2026-11-19 本机运行的结果。输入是项目自带的 120,000 行可重复演示数据，不是阿里天池全量数据；这些数字用于验证代码链路，不应直接写入简历作为真实淘宝数据结论。

- ODS：120,007 行，10 个日期分区（其中 1 个分区用于模拟越界日期）。
- DWD：119,955 行，过滤 52 行，过滤率 0.04%，主键重复数 0。
- DWS：用户粒度 41,860 行，商品粒度 87,454 行，类目粒度 4,500 行；三张表粒度重复键均为 0。
- ADS：DAU、留存、漏斗、类目 Top10、复购率 5 张表全部产出。
- Pandas 与 Spark：DAU、次日留存分子、漏斗 UV 三项交叉验证全部一致。
- 调优实验：shuffle 200 分区 0.741 秒，400 分区 0.292 秒；普通 join 0.662 秒，broadcast join 0.511 秒。
- 图表：`output/charts/` 下生成 DAU、留存、漏斗、类目 Top10 四张 PNG。
